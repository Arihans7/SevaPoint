# SevaPoint Digital Service Centre

A responsive frontend demo built with React + Vite. It follows the supplied reference screenshots but uses a more restrained navy, white, blue and muted amber visual identity.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Included in this first version

- Responsive homepage and mobile navigation
- Services directory with search
- Jobs & Forms section with category filters
- Digital tools section
- Working in-browser image resizer
- Working single-image-to-PDF demo
- GST calculator
- About / How it works sections
- Contact enquiry form UI (demo only)
- Placeholder business details that need client confirmation

## Important before publishing

- Replace `[Add full shop address]`, `[Add business phone number]`, and similar placeholders with approved business details.
- Confirm the actual service list and opening hours with the owner.
- Recruitment entries are demonstration content. Verify notifications, dates, vacancies and official links before publishing. Do not treat demo dates as live information.
- The contact form does not send or store submissions. Connect a backend or approved form service before relying on it.
- Customer login, document uploads, admin features and application tracking are intentionally not implemented in this frontend phase.
- Add a privacy policy and terms before collecting any personal data.
